# Chapter & Co. Bookstore

A beginner-friendly responsive bookstore website built with HTML and Tailwind CSS.

## Pages

- Home
- Books
- Gallery
- Contact

## Tech Used

- HTML5
- Tailwind CSS
- Git & GitHub
- Vercel 

## Features

- Mobile-first responsive design
- Mobile, tablet and desktop layouts
- Tailwind CSS utility classes
- Accessible contact form
- Responsive image gallery
- CSS Grid for book cards
- Flexbox for the Why Choose Us section
- Business hours

## Breakpoints

The layout is designed for:

- Mobile: around 375px
- Tablet: around 768px
- Desktop: around 1280px

## Run locally

No build tool is required for this beginner version.

1. Download or clone the project.
2. Open `index.html` in a browser.
3. For the best development experience, use VS Code with the Live Server extension.

## Deployment

This is a static website and can be deployed using Vercel .
