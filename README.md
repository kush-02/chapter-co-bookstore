# Chapter & Co. Bookstore

A beginner-friendly responsive bookstore website built with HTML and Tailwind CSS.

## Pages

- Home
- Books
- Gallery
- Contact

## Tech Used

- HTML5
- Tailwind CSS
- Git & GitHub
- Vercel 

## Features

- Mobile-first responsive design
- Mobile, tablet and desktop layouts
- Tailwind CSS utility classes
- Dark mode
- Semantic HTML
- Accessible contact form
- Responsive image gallery
- CSS Grid for book cards
- Flexbox for the Why Choose Us section
- Business hours
- Google Maps embed
- Hover and focus states

## Breakpoints

The layout is designed for:

- Mobile: around 375px
- Tablet: around 768px
- Desktop: around 1280px

## Run locally

No build tool is required for this beginner version.

1. Download or clone the project.
2. Open `index.html` in a browser.
3. For the best development experience, use VS Code with the Live Server extension.

## Git workflow

Example meaningful commits:

1. `Initial bookstore structure`
2. `Add homepage hero section`
3. `Add featured books`
4. `Add why choose us section`
5. `Add books page`
6. `Add gallery page`
7. `Add contact form`
8. `Add dark mode`
9. `Add responsive navigation`
10. `Add README and deployment details`

Create a feature branch:

`git checkout -b feature/contact-page`

After completing the work:

`git add .`

`git commit -m "Add accessible contact page"`

Then push the branch and create a Pull Request on GitHub. Merge it into `main`.

## Deployment

This is a static website, so it can be deployed directly to Vercel or Netlify.

For Vercel:

1. Push the project to GitHub.
2. Open Vercel.
3. Import the GitHub repository.
4. Keep the project as a static site.
5. Deploy.
6. Open the generated live link on both Wi-Fi and mobile data.

## Note

The images use public Unsplash image URLs. If you want a completely self-contained project, download the images into `assets/images/` and replace the image URLs with local paths.
